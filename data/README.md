# Data

The FourTex dataset was provided by the course *Strategic Marketing Decision Making* (Erasmus University Rotterdam) and cannot be shared.

It contains 200 weeks of data (2018 onwards) with these columns:

| Column | Description |
|---|---|
| `Date` | Week |
| `TikTok` | TikTok ad spend |
| `Facebook` | Facebook ad spend |
| `Google Ads` | Google Ads spend |
| `Sales` | Weekly sales |

To run the analysis, save the file as `data/marketing_mix.csv`.
